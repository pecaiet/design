# Input with icon

A text field with an icon inside it, for quick add and search.

- `.pc-input-group` holding a 16px icon `<svg>` first, then the `.pc-input`; an optional `.pc-input-group-end` on the right for a `.pc-kbd` hint.
- Quick add adds on Enter and empties itself. Give the field an `aria-label` when it has no visible label.
