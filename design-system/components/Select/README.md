# Select

Choosing one option from a list, using the browser's own menu.

- Prefer the **Picker** for every choice: it looks the same, can search, and is a sheet on phones. This native select stays only until an app has moved.
- `.pc-select` wrapping a native `<select>` and a chevron `<svg>` after it. Label it with a `.pc-label` in a `.pc-field`.
- For choices that need dots, icons or groups (Move to), use the Dropdown menu with radio items instead.
