# Avatar

The email's first letter in a small circle: who is signed in.

- `<span class="pc-avatar">A</span>`: a 22px circle with a thin `border`, on `card`, the letter upper case in 10px semibold `foreground`. One size.
- Always next to the email, never alone: people have an email, not a name or a photo, so the letter only repeats it. It sits in the sidebar's account row, the top bar's account row and at the foot of the settings modal's nav.
- Photos, more sizes, coloured initials and stacks of avatars are not designed yet; they come when an app needs them.
