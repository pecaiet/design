# Card

A white, slightly raised panel that groups one task on a page.

- `.pc-card` holding `.pc-card-header` (`.pc-card-title`, optional `.pc-card-description`), `.pc-card-content`, and an optional `.pc-card-footer` for actions, aligned right.
- One subject per card: "Email address", "Sessions", "Delete account". A delete card holds only its red button.
