# Link

An underlined link inside running text, in the text colour.

- `<a class="pc-link">`. Use it for navigation inside sentences: "Forgot password?", "Create an account".
- The text colour (`foreground`), medium weight, with a soft underline at rest (`muted-foreground` at 45%) that turns solid in the text colour under the pointer. The underline stays, so a link never relies on colour alone; in a muted line ("New here?") it stands out by being darker.
- Rows that open something use the Table row link or a sidebar item instead, not `.pc-link`.
