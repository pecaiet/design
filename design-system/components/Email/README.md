# Email

The password reset email, in Senin's light colours.

- Mail apps drop stylesheets, so the email writes inline styles with hex values: page #f4f7fa, card #ffffff with border #e0e6ee, text #1c2733, secondary text #566577, button #0b7a75 with white text and 10px corners.
- Light only. Figtree with a system fallback.
