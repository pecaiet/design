# Badge

A short round label for a status or a fact on a row.

- `.pc-badge` (neutral), `.pc-badge-primary` (the one status that matters, such as Admin), `.pc-badge-soft` (a quiet label: a light teal tint over whatever is behind it), `.pc-badge-outline` (plain facts: User, This device, Public), `.pc-badge-destructive` (Failed).
- Two sizes: 20px tall with 12px words (the default), and `.pc-badge-small`, 16px tall with 10px words, for tight spots such as on an avatar. Every style comes in both.
- One or two words. Not clickable.
- A removable value (a reminder) is a `.pc-chip` with an optional icon and a `.pc-chip-remove` button with an `aria-label`.
